# 后端开发工程师（Python/Go方向）

## 基本信息

- **岗位名称：** 后端开发工程师
- **所属部门：** 技术部 / 后端开发组
- **工作地点：** 杭州
- **岗位类型：** 全职
- **薪资范围：** 校招 20-35K | 社招 30-50K

## 岗位职责

1. 负责公司核心业务系统的后端开发与维护，保障系统高可用和高性能
2. 参与系统架构设计与技术方案评审，推动技术栈升级和优化
3. 编写高质量的、可维护的代码，编写相关技术文档和接口文档
4. 与产品经理、前端工程师紧密协作，确保项目按时高质量交付
5. 参与线上问题排查和系统稳定性治理，保障系统SLA
6. 关注行业技术发展趋势，引入合适的新技术提升团队效率

## 任职要求

### 基本要求

1. 本科及以上学历，计算机科学、软件工程或相关专业
2. 熟练掌握 Python 或 Go 语言（两者都会者优先），了解常用 Web 框架（如 Flask/Gin/FastAPI）
3. 熟悉 MySQL/PostgreSQL 等关系型数据库，具备SQL优化能力
4. 了解 Redis 等缓存技术，理解缓存策略和应用场景
5. 熟悉 Linux 操作系统，掌握常用命令和 Shell 脚本
6. 熟练使用 Git 进行版本控制
7. 良好的沟通能力和团队协作精神，有责任心和Owner意识

### 加分项

1. 有分布式系统或微服务架构开发经验
2. 了解 Docker/Kubernetes 等容器化技术
3. 有消息队列（Kafka/RabbitMQ）使用经验
4. 有高并发系统开发或性能优化经验
5. 有开源项目贡献或技术博客
6. 了解 CI/CD 流程和自动化测试

### 校招附加

1. 2024届应届毕业生，本科或硕士学历
2. 有互联网公司实习经验者优先
3. 有ACM/数学建模等竞赛获奖者优先
4. GPA 3.0/4.0 及以上

### 社招附加

1. 2年以上后端开发工作经验
2. 有大型互联网公司工作经验者优先
3. 有技术方案设计和技术选型经验
4. 有团队协作和项目管理经验

## 福利待遇

- 六险一金、年度体检
- 弹性工作制、远程办公支持
- 技术培训和学习成长预算
- 餐饮补贴、交通补贴
- 年度团建、节日福利
