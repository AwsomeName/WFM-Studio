## 1. 产品定位

**Uni-Studio** 是面向内容/写作/营销专业人士的 AI 内容生产桌面应用。

核心定位：不是"VS Code 换皮"，而是**一个全新产品**——AI 驱动的内容工作台。

---

## 2. 用户画像

| 用户 | 特征 | 核心需求 |
|------|------|----------|
| 营销策划 | 不懂编程，熟悉 Office/WPS | 一键生成 PPT 方案，精细调整排版 |
| 标书撰写 | 熟悉招投标流程，Word 重度用户 | 从需求到标书的 AI 生成 + 合规审查 |
| 内容运营 | 熟悉 Markdown，轻度技术背景 | 文案/文章 AI 创作 + 模板化输出 |

---

## 3. 功能需求

### 3.1 P1：统一中文工作台

- 产品名显示 "Uni-Studio"
- 除大标题外尽量中文（菜单、面板、提示、状态）
- 裁掉终端/调试/Git/测试等开发者功能
- 右侧 AI 面板默认可见

### 3.2 P2：PPT 编辑

- **整体生成**：prompt → AI 生成完整 PPTX → 自动打开
- **精细编辑**：PPTist 所见即所得编辑器 → 拖拽排版、文本修改、动画设置
- 两种模式无缝切换

### 3.3 P3：标书/方案生成

- **一键生成**：需求描述 → 大纲 → 分章节 → 评审 → 格式化输出
- **精细调整**：逐章节修改、补充、润色
- 输出格式：docx / markdown / pdf

### 3.4 P4：AI 对话面板

- 与后端 Agent Gateway 实时对话
- SSE 流式回复
- 工作区上下文自动注入

### 3.5 P5：后端可定制性

- 多引擎可选（CrewAI / Anthropic / MAF / AgenticX）
- 工具层统一（ToolGateway + MCP 聚合）
- recipe_id 预置流水线

---

## 4. 成功指标

| 指标 | 目标 |
|------|------|
| 首次生成 PPT 时间 | < 60s |
| 精细编辑 PPT 响应 | < 200ms 交互延迟 |
| 标书生成完整度 | > 85% 章节 AI 自动完成 |
| 端到端闭环验证 | Chat → 生成 → 编辑 → 保存 一条链路跑通 |

---

## 5. 非目标（第一版不做）

- 多人协作编辑
- 资源市场（Phase 5 后续）
- 海报/图表编辑器（Phase 6 后续）
- 移动端适配
