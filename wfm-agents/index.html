🤖 WFM Agents

WFM Studio 的 Agent 后端服务 — FastAPI + OpenAI Agents SDK

架构概览

自 2026-05 起，对话后端基于 OpenAI Agents SDK（wfm_agents/agent_v2/），不再使用自研 runner。

wfm_agents/
├── agent/              # deprecated，仅保留模块声明
├── agent_v2/           # ★ 当前运行时
│   ├── agents.py       # Agent 定义：router + text_to_cad / cad_review / docx_review
│   ├── context.py      # WfmAgentContext(workspace_root)
│   ├── tools.py        # workspace + CAD + DOCX 工具
│   ├── sse.py          # SSE 事件编码
│   └── runner.py       # run_chat() / run_chat_stream() — 路由层唯一入口
├── cad/                # DXF 解析 / 审图 schema
├── gateway/            # [DEPRECATED] 旧 AgentGateway
├── engines/            # [DEPRECATED] 旧 EngineAdapter
├── routes/             # HTTP 薄路由
└── server.py           # FastAPI 入口

环境变量

变量说明默认值
WFM_OPENAI_API_KEY / OPENAI_API_KEYAPI Key（必填）—
WFM_OPENAI_BASE_URL上游 base URL（空）
WFM_AGENT_MODEL模型 IDgpt-4o-mini
WFM_AGENT_TEMP温度0.3
WFM_AGENT_MAX_TOOL_ROUNDS工具循环上限16
WFM_AGENT_API上游能力探测chat

快速启动

cp .env.example .env          # 填入 WFM_OPENAI_API_KEY 等
uv sync --extra dev
uv run uvicorn wfm_agents.server:app --reload --host 127.0.0.1 --port 8765

也可使用 ./scripts/dev.sh（含 DevUI）或 ./scripts/dev-minimal.sh（最小闭环）。

API 接口

MethodPath说明
GET/v1/health健康检查
POST/v1/chat对话（agent_v2 runner）
POST/v1/chat/streamSSE 流式对话
POST/v1/cad/reviewCAD 审图（同步）
POST/v1/cad/review/streamCAD 审图（SSE 流式）
POST/v1/workspace/write工作区内写文件
POST/v1/workspace/read工作区内读文件
POST/v1/admin/mcp/reload重载 MCP 工具列表
